# node.js_learnZIPfile

Node.js learning project.

## Setup

1. Install dependencies with `npm install`.
2. Set `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, and `TWILIO_PHONE_NUMBER`
   in the environment.
3. Configure the database in `config/config.json`.
4. Start the server with `node app.js`.

The Twilio credentials are required when the application starts and should not
be committed to the repository.
